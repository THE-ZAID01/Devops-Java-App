# Devops-Java-App
# SEA Lab — Experiment 8: DevOps CI/CD Pipeline

## Overview
This repository contains the implementation of Experiment 8 for the Software 
Engineering and Architecture (SEA) Lab, focused on introducing core DevOps 
practices through a hands-on CI/CD pipeline setup.

## Aim
To implement a basic DevOps pipeline using GitHub Actions for Continuous 
Integration and Continuous Deployment (CI/CD) of a simple Java application.

## Key Concepts Covered
- Introduction to DevOps and its role in modern software delivery
- Continuous Integration (CI) and Continuous Deployment (CD)
- Automated build, test, and run workflows using GitHub Actions
- YAML-based workflow configuration

## Tech Stack
- **Language:** Java
- **CI/CD Tool:** GitHub Actions
- **Version Control:** Git & GitHub

## Pipeline Flow
Push Code → GitHub Actions Triggered → Checkout → Setup Environment → 
Run Tests → Run Application → Pipeline Success/Failure
